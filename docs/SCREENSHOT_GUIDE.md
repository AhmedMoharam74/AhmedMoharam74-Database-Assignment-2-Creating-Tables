## Task 4 — three database constraint errors

After the workbook data has been loaded and the constraints are enabled, open the relevant table using **Edit Top 200 Rows** in SSMS. Attempt each invalid value, capture the actual error message, then cancel/revert the invalid edit so the database remains valid.

1. **Duplicate bid amount in the same auction**
   - Open `Sales.Bid` (it remains in `Sales`).
   - Add a test row using an existing `AuctionId` and repeat an `Amount` already used by that same auction.
   - Expected constraint: `UQ_Bid_Auction_Amount`.
   - Save screenshot as `docs/screenshots/error-duplicate-bid.png`.

2. **Held amount greater than balance**
   - Open `People.Wallet`.
   - Edit one row so `HeldAmount` is greater than `Balance`.
   - Expected constraint: `CK_Wallet_HeldAmount`.
   - Save screenshot as `docs/screenshots/error-held-over-balance.png`.

3. **An item inspected by its own seller**
   - Open `Inventory.Item`.
   - Edit one row so `InspectorMemberId` equals its `SellerMemberId`.
   - Expected constraint: `CK_Item_SellerInspector`.
   - Save screenshot as `docs/screenshots/error-seller-is-inspector.png`.

## Task 4 — export the data-only script

After all data is loaded:
1. In SSMS Object Explorer, right-click `BidNile`.
2. Choose **Tasks → Generate Scripts**.
3. Select the relevant tables (or the whole database if your instructor expects all data).
4. Open **Advanced** and set **Types of data to script** to **Data only**.
5. Finish the wizard and save/replace `database/BidNile_Data.sql`.

Do not type the data script by hand. This file must be generated by SSMS as required by the assignment.
