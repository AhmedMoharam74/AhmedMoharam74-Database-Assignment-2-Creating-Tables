## Run
1. Open `database/BidNile.sql` in SSMS (SQL Server 2019+).
2. Execute the full script on a fresh SQL Server instance.
3. For Task 4, use the workbook sheets to enter/import data in FK-safe order. Enter rows only through SSMS (no hand-typed data statements).
   - Import `Country`, then `City`, then `Member`. Identity values are generated by SQL Server; the workbook assumes the five cities receive CityId 1–5 in sheet order.
   - Import `Warehouse` with NULL `ManagerMemberId` and `ManagerSince`, then `Employee`.
   - After employees exist, use Edit Top 200 Rows to set each warehouse manager (an employee GUID) and manager start date.
   - Import `Wallet`, `Category`, `Item`, `ItemPhoto`, `Auction`, `Bid`, then `AuctionFollower`. Keep the item insertion order so ItemId 1–5 and AuctionId 1–6 match the workbook rows.
4. After entering the data, use Tasks → Generate Scripts → Advanced → Types of data to script = Data only to generate `BidNile_Data.sql`.
5. Capture the three required constraint-error screenshots and the Accepted LeetCode submission screenshots in `docs/screenshots/`.

## Important
The Excel workbook is an import source, not the required final wizard-exported `BidNile_Data.sql`. The final data-only SQL file and screenshots must be generated from your own SSMS session. The LeetCode screenshots and GitHub PR must also come from your own accounts.
